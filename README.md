# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

## 架构分层

规则判断、持久化与界面展示彼此独立：

- `js/rules.js` —— 规则层（纯领域逻辑）：包装清单、签收、返工、缺陷、状态流转与风险统计的全部判断，不依赖 DOM 与 localStorage，可独立测试。
- `js/store.js` —— 持久化层：localStorage 读写与旧数据迁移（自动补齐闭环所需的数组字段）。
- `js/ui.js` —— 界面层：渲染与事件处理，调用规则层判断、持久化层保存后整体重渲染，保证列表、风险统计与刷新后的状态一致。

## 交付包装与签收闭环

- 作品进入「待交付」后可创建包装清单，且同一作品**只能有一份未结束清单**；创建后进入「已包装（待签收）」。
- 包装后若调整**胎体、纹样、线条、缺陷或阴干日期**，未结束清单**立即失效**并退回「待交付」；记录缺陷同样触发失效。
- 签收必须填写**收货人、实际交付日期、唯一签收号**，缺项或签收号重复一律拒绝；签收后清单随之结束，作品进入「已签收」。
- 签收后补做修复只**追加返工记录**，原签收与缺陷历史完整保留；返工完成后退回「待交付」，可重新包装并再次签收。
- 「已包装 / 已签收 / 返工中」为闭环状态，只能通过包装、签收、返工动作流转，不可手动改状态进入。

## 其他功能

- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付、已包装、已签收、返工中七列。
- 风险统计：总作品、待签收、已签收、返工中、缺陷作品、逾期未交付、清单失效次数、累计返工。
- 今日待阴干、缺陷作品、最近交付（已签收）三类列表。
- 详情弹窗展示包装清单、签收记录、返工记录、缺陷历史与流转记录，支持编辑作品与记录缺陷。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。
